## What VoiceKey does

VoiceKey is a lightweight Windows utility that connects a keyboard key or HID remote button to voice features in supported desktop apps and websites.

- 🎤 **Native Voice** — start/stop the active app's own voice or recording control.
- ✍️ **Dictation** — speech-to-text through Deepgram and automatic insertion into the focused field.
- 🎮 **G10S support** — hardware Mic button can work as a START/STOP toggle.
- 🌐 **Browser-specific routing** — routes are isolated per site/browser to avoid regressions.
- 🔒 **Local privacy controls** — credentials are protected with Windows DPAPI; diagnostics do not include recognized text or audio.

## Supported targets

Current Working Beta includes dedicated routes for targets such as:

**Telegram Desktop · WhatsApp Desktop/Web · ChatGPT · Gemini · Google Search · Google Translate · YouTube · Viber · Antigravity**

Compatibility may vary by browser and UI version. Verified routes are kept isolated so a fix for one target does not silently change another.

## Update channel

VoiceKey checks this **public release repository** for updates.  
The application source code is maintained separately in a private repository.

## Working Beta

This is an active beta. Browser or app UI changes can require a VoiceKey update. Built-in routing data ships inside the application rather than as a public route catalog.
